# Mini-brain

Личный ИИ-помощник с оригинальным интерфейсом чата. Frontend — статический сайт для GitHub Pages; запросы к модели идут через отдельный FastAPI-сервер. Ключ OpenRouter хранится только на сервере и никогда не добавляется в репозиторий или браузерный код.

## Как устроен проект

- `index.html`, `styles.css`, `app.js`, `config.js` — сайт, публикуемый GitHub Pages.
- `api/` — серверный API на FastAPI, который проверяет запрос и обращается к OpenRouter.
- `render.yaml` — blueprint для развёртывания backend на Render.

История чатов сохраняется локально в браузере посетителя. Передача файлов и потоковая выдача пока не поддерживаются. Бесплатные модели и тарифы провайдера могут иметь ограничения и временно не отвечать.

## Публикация сайта

1. В GitHub откройте **Settings → Pages** и выберите источник публикации из ветки `main`, папка `/(root)`.
2. После публикации сайт будет доступен на `https://vnmhimvm.github.io/`. Если используете собственный домен, добавьте его в настройки Pages и включите HTTPS.
3. До настройки API интерфейс загрузится, но отправка сообщений покажет, что сервер не подключён.

## Развёртывание API на Render

1. Создайте Web Service из этого репозитория либо примените `render.yaml` через **New → Blueprint**. Для службы используйте корень `api`, команду сборки `pip install -r requirements.txt` и запуска `uvicorn main:app --host 0.0.0.0 --port $PORT`. Blueprint уже содержит эти настройки.
2. Создайте API key в своём аккаунте OpenRouter и добавьте его только в Render как секретную переменную `OPENROUTER_API_KEY`. Не вставляйте ключ в issue, frontend, `config.js`, репозиторий или переписку.
3. Установите `OPENROUTER_MODEL` в поддерживаемый OpenRouter ID модели. По умолчанию используется `openrouter/free`; доступность бесплатных моделей и лимиты определяет провайдер.
4. Установите `ALLOWED_ORIGINS` в точный origin опубликованного сайта, без завершающего слэша, например `https://vnmhimvm.github.io`. Для собственного домена укажите его отдельно. Несколько origin перечисляются через запятую.
5. После публикации Render скопируйте публичный URL службы, например `https://mini-brain-api.onrender.com`.
6. В `config.js` укажите этот публичный адрес в `apiBaseUrl`, без `/api/chat`, затем опубликуйте обновление frontend:

   ```js
   window.MINI_BRAIN_CONFIG = {
     apiBaseUrl: "https://mini-brain-api.onrender.com"
   };
   ```

`apiBaseUrl` не является секретом. Ключ OpenRouter должен оставаться только в серверной переменной окружения. Если адрес службы изменился, обновите `config.js`.

## Локальный запуск и проверка

Запустите backend из папки `api` (Python 3.10+):

```powershell
cd api
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
$env:OPENROUTER_API_KEY = "ваш-ключ-для-локальной-разработки"
$env:ALLOWED_ORIGINS = "http://localhost:5500"
uvicorn main:app --reload
```

Во втором терминале запустите статический сайт из корня репозитория, например `python -m http.server 5500`. Откройте `http://localhost:5500`, а в `config.js` укажите `http://127.0.0.1:8000`. `ALLOWED_ORIGINS` должен совпадать с origin frontend-сервера. Проверки backend, включая тест с подменённым ответом провайдера (без внешнего запроса), запускаются из папки `api`:

```powershell
python -m unittest
```

API ограничивает тело запроса 64 КБ, число сообщений — 20, длину одного сообщения — 12 000 символов и частоту — 20 запросов в минуту с одного IP на экземпляр сервера. Это базовая защита от случайного злоупотребления, а не полноценная пользовательская аутентификация; для публичного сервиса также настройте лимиты/расходы в аккаунте провайдера. CORS по умолчанию разрешает только `https://vnmhimvm.github.io`, но CORS не блокирует прямые запросы вне браузера. Ошибки провайдера возвращаются без передачи его внутреннего ответа или ключа клиенту.
